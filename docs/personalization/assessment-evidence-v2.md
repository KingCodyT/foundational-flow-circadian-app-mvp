# Assessment Evidence v2

Status: Review

The website assessment now uses five evidence sections:

1. Morning Light
2. Daytime Environment
3. Evening Light
4. Sleep Timing
5. Life Constraints

Location, latitude, season, sunrise, sunset, and day length are derived from environmental context rather than self-scored questionnaire answers.

Meal timing is separated into distinct evidence:
- meal timing regularity
- last meal timing relative to bedtime

Schedule variability and home environmental control remain context constraints rather than coaching-performance judgments.

The root route opens the assessment front door. The profile remains available at `/you`.
