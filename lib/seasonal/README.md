# Regional meal ingredients

Harvest facts retrieved 2026-10-02 from GRACE Communications Foundation's Seasonal Food Guide (https://www.seasonalfoodguide.org/about). The guide aggregates NRDC, state agriculture departments and university extension calendars. `harvest-calendar.json` contains only crop names and factual half-month availability for a curated set of common meal ingredients; it does not reproduce descriptions, images or recipe text. Periods 1–24 are early/late January through December (day 16 begins late month). These are typical regional availability windows, not live farm inventories or guarantees of outdoor harvest. Storage and growing methods can affect availability; users should confirm with growers.

All 50 states and DC are selectable; California and Florida also have north/south calendars. Boundaries are simplified state polygons from https://github.com/PublicaMundi/MappingAPI/blob/master/data/geojson/us-states.json (retrieved 2026-10-02). Removed density data. Exact polygon matches are tried first, then a 0.05-degree boundary tolerance for simplified coastlines. This is approximate and user-correctable. Coordinates are matched locally, never sent to a geocoder. CA 36°N and FL 28°N splits are approximate product defaults, not official growing-zone borders. Users can override the result. Out-of-coverage locations are never mapped to the nearest U.S. state.

Meal templates distinguish seasonal produce from protein and pantry staples, whose local origin is not verified. Missing produce falls back explicitly to general ideas. To expand ingredient coverage, add verified factual calendar rows and test all periods/regions; do not infer a harvest season from hemisphere alone.
